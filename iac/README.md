# Инфраструктура как код

Первоначальная конфигурация гостевой ОС находится рядом с приложением.
Создание ВМ, CPU/RAM, диск, загрузка ISO, сеть и правила доступа принадлежат
оператору. Конфигурация не обращается к API гипервизора.

[FCOS: подготовка Ignition, установка и проверка](fcos/README.md).

Шаблоны запуска приложения остаются в `deploy/quadlet`; устанавливаются
сгенерированные файлы проверенной поставки по
[инструкции центра](../docs/center-deployment.md).
CI/CD, Ansible и автоматический updater приложения сюда пока не входят.

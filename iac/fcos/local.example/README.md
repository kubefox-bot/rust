# Публичный SSH-ключ этой установки

Создайте соседний каталог `iac/fcos/local/` и скопируйте в
`iac/fcos/local/admin.pub` **публичный** SSH-ключ администратора, например
содержимое `~/.ssh/id_ed25519.pub`. Файл содержит одну или несколько полных
строк OpenSSH public key. Готовый ключ здесь намеренно не поставляется.

Приватный ключ остаётся на вашем компьютере. Не копируйте сюда файлы
`id_ed25519`, `id_rsa`, пароли, токены, recovery key или TLS private keys.
Каталог `local/` исключён из Git; это не заменяет проверку его содержимого.
При подготовке Ignition в staging копируется только явно указанный
`admin.pub`, а не весь каталог.

Эта конфигурация даёт ключу доступ к административному пользователю `core`.
Служебный пользователь `hmail-center` не получает SSH-ключей или sudo.
Сначала проверьте владельца и назначение публичного ключа, затем собирайте
Ignition. Пустой файл или отсутствие файла блокируют подготовку.
